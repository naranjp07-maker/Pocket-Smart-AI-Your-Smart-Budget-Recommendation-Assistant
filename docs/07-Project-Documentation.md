# Phase 7: Project Documentation

## Project Name
PocketSmart AI – Your Smart Budget Recommendation Assistant

## 1. Introduction
PocketSmart AI is an AI-powered web application that helps users plan their budgets and receive personalized recommendations for different needs.

## 2. Purpose
The purpose of this project is to help users make budget-conscious decisions through AI-generated suggestions.

## 3. Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Python and FastAPI
- Database: SQLite
- AI Integration: Google Gemini API
- Development Environment: Visual Studio Code
- Version Control: Git and GitHub

## 4. Main Features
- User registration and login
- Interior design planning
- Party planning
- Jewelry recommendations
- Budget-based recommendations
- Plan history
- Product search links

## 5. System Requirements

### Software Requirements
- Windows, Linux, or macOS
- Python
- Visual Studio Code
- Modern web browser
- Internet connection for AI API access

### Hardware Requirements
- Computer or laptop
- Minimum 4 GB RAM recommended

## 6. Installation and Setup

1. Clone or download the project repository.
2. Open the project folder in Visual Studio Code.
3. Create and activate a Python virtual environment.
4. Install dependencies using `pip install -r requirements.txt`.
5. Configure the Gemini API key in the `.env` file.
6. Start the FastAPI application.
7. Open the application in a web browser.

## 7. Usage Instructions

1. Open the PocketSmart AI application.
2. Register or log in.
3. Select a planning category.
4. Enter the budget and preferences.
5. Submit the form.
6. View the generated recommendations.
7. Check saved plans in the history section.

## 8. Security
- Keep API keys in environment variables.
- Do not upload `.env` files to GitHub.
- Protect user authentication credentials.

## 9. Limitations
- AI recommendations depend on API availability.
- Product search links may not reflect live prices or stock.
- Recommendation quality depends on the information provided by the user.

## 10. Conclusion
PocketSmart AI provides a convenient platform for budget planning and personalized recommendations.
