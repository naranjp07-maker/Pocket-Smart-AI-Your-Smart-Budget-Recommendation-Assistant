# Phase 8: Project Demonstration

## Project Name
PocketSmart AI – Your Smart Budget Recommendation Assistant

## 1. Introduction
This phase demonstrates the working process and features of the PocketSmart AI application.

## 2. Project Overview
PocketSmart AI is an AI-powered budget recommendation application that helps users plan interiors, parties, and jewelry purchases based on their preferences and budget.

## 3. Demonstration Steps

### Step 1: Launch the Application
Start the backend server and open the application in a web browser.

### Step 2: User Registration and Login
Register a new account or log in using existing credentials.

### Step 3: Select a Planning Category
Choose one of the available categories:
- Interior Planning
- Party Planning
- Jewelry Recommendations

### Step 4: Enter Budget and Preferences
Enter the budget and other required details.

### Step 5: Generate Recommendations
Submit the form and view the recommendations generated by the application.

### Step 6: View Plan History
Open the history section to view previously saved plans.

### Step 7: Product Search
Use the available product search links to explore relevant products.
