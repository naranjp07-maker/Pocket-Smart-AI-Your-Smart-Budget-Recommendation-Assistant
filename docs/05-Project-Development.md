# Phase 5: Project Development

## Project Name
PocketSmart AI – Your Smart Budget Recommendation Assistant

## 1. Introduction
PocketSmart AI is a web-based application designed to help users plan their budgets and receive personalized recommendations for interiors, parties, and jewelry.

## 2. Frontend Development
The frontend is developed using:
- HTML for page structure
- CSS for styling and layout
- JavaScript for user interactions and API communication

## 3. Backend Development
The backend is developed using Python and FastAPI.

Backend modules include:
- User authentication
- Budget planning APIs
- AI recommendation integration
- Plan history management

## 4. Database Development
SQLite is used as the database.

The database is designed to store user information and saved plans.

## 5. AI Integration
Google Gemini API is integrated to generate recommendations based on user preferences and budget details.

A fallback mechanism is included to handle situations where AI recommendations are unavailable.

## 6. Main Features
- User registration and login
- Interior planning
- Party planning
- Jewelry recommendations
- Budget-based suggestions
- Plan history
- Product search links

## 7. Development Tools
- Visual Studio Code
- Python
- FastAPI
- SQLite
- Google Gemini API
- Git and GitHub
