# Pocket Smart AI: Your Smart Budget & Recommendation Assistant

## Project Overview
Pocket Smart AI is an AI-powered smart budget management
and recommendation assistant designed to help users track
expenses, manage budgets, and make smarter financial decisions.

## Objectives
- Track daily income and expenses
- Manage monthly budgets
- Analyze spending habits
- Provide smart financial recommendations
- Help users improve money management

## Planned Features
1. User Registration and Login
2. Expense Tracking
3. Income Management
4. Monthly Budget Planning
5. Expense Analysis
6. AI-Based Recommendations
7. Dashboard and Reports
